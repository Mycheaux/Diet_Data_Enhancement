# Task History Summaries

This folder stores reusable task-memory notes for the nitrate/oral microbiome project.

These files are intended for future LLM agents and human collaborators who need to recreate the work, understand why decisions were made, or generalize the workflow into a repeatable pipeline for future HPP paper-generation tasks.

## Files

- `01_hypothesis_discovery_to_natcom_paper.md`: conversation and decision history from the first broad HPP hypothesis search through the final Nature Communications-style manuscript package.
- `02_diet_data_enhancement_process.md`: practical process summary for how the diet enhancement and exposure reconstruction were done, including principles that should transfer to other dietary/chemical hypotheses.
